先有业务闭环，再有 AI 提效。根扎进调研和方案，树干是 IP 大脑，枝叶每天开出热点、选题、文案和成片，最后结出可复用的知识库。点任意方块，小精灵云云会飞过去，告诉你这一步怎么做、用什么工具。

怎么读这棵树

从下往上，就是从进入项目到最终产出

根系阶段一 · 进入项目：① 调研、② 定方案。根扎得准，后面才不跑偏。
树干阶段二 · 搭建 AI 员工：③ IP 大脑，四份核心 MD 文档是它的年轮。
枝叶阶段三 · 日常执行：④ 热点 → ⑤ 选题 → ⑥ 文案 → ⑦ 拍剪发，树液沿枝条一路往上流。
树冠支撑体系：⑧ 素材库、⑨ Skill 技能包，把每天跑出来的爆款和方法论沉淀下来。
果实最终产出：⑩ 语料收集，结出可复用到任意 IP 的知识库。
